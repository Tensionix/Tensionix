## The tools

All of them are built the same way, and that is the point.

- **Portable** — a program lives in its own folder: no installer, nothing in the registry, it leaves together with the folder.
- **Verifiable** — when a program claims something, it shows what the claim rests on.
- **Open** — Apache 2.0. None of it is for sale.
